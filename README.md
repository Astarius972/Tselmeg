# Tselmeg

A personal website for Tselmeg — photos, hobbies and little things about her, in English and Mongolian.

Built with Next.js, GSAP and Lenis.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:3000

All the text (both languages) lives in `data/content.js`. Photos are in `public/gallery`, the song in `public/music`.
